Speed Chat

Short conversations with a few different classmates. The follow-up question is what keeps each one going.

Pairs, then rotateNo materials
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“What do you like about ___?” · “Why is that?” · “How about you?”

How to run it

Before you start

Arrange pairs and decide how partners will change. Use the one-minute timer for each person’s turn. Students can choose another question if they prefer.

The 20 minutes

  1. 0–3 min
    Show a short exchange

    Answer a question, ask “Why?” or “How about you?”, and respond. Make clear that both partners need a turn.

  2. 3–9 min
    Talk, then change partners

    Show a question and give each person about a minute. Change partners and use the next question. Leave time to move.

  3. 9–16 min
    Try two more questions

    Continue with new partners. Ask each student to add a follow-up question before sharing their own answer.

  4. 16–20 min
    Remember an idea

    Students tell a partner an interesting idea they heard. Ask which follow-up question got a longer answer.

Worth keeping in mind

If answers stop after one word, model a follow-up. “Why?” is often enough.

The English they’re using

Taking turns · Asking follow-up questions · Listening for detail

Make it easier or harder

Keep it simple: Show the next question early and let students plan a few words.

Take it further: Ask two follow-up questions before giving your own answer.
