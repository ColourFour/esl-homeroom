Sentence Detective

Find what needs changing in a sentence, agree on a better version and explain the change.

Pairs → groups of 4Paper + pens
Time left

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“We changed ___ to ___ because ___.” · “The clue is ___.”

How to run it

Before you start

Show one sentence at a time. Pairs use paper to write a correction. Leave the suggested answer hidden until they have had a go.

The 20 minutes

  1. 0–3 min
    Find a clue

    Read the sentence and ask what they notice. Point to a time word or a subject if they need a place to start.

  2. 3–9 min
    Compare corrections

    Pairs write a new version and explain their choice. Reveal the suggested answer and compare.

  3. 9–16 min
    Try a few more

    Work through the next sentences. Join another pair to discuss before revealing. If there is time, write a simple puzzle for the other pair.

  4. 16–20 min
    Explain one change

    Each student explains a correction to a partner. Take two examples and repeat the useful sentence pattern.

Worth keeping in mind

They don’t need the name of the grammar rule. Ask what changed and why it makes sense.

The English they’re using

Reading carefully · Correcting sentences · Explaining a change

Make it easier or harder

Keep it simple: Offer two corrected versions to choose from.

Take it further: Find another correct way to express the same meaning.
