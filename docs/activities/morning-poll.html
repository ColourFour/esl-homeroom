Morning Poll

Take a quick class vote, discuss the choices, then use the results to practise comparisons.

Class → small groupsNo materials
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“Most of us chose ___.” · “___ is more popular than ___.” · “I chose ___ because ___.”

How to run it

Before you start

Read the question and count a show of hands. Enter the totals using the vote buttons. Students can also move to different parts of the room to choose.

The 20 minutes

  1. 0–3 min
    Take the vote

    Check that everyone understands the options. Count one vote per person and leave the results hidden for now.

  2. 3–9 min
    Explain the choices

    Partners explain their votes and ask each other a question. Join another pair and compare reasons.

  3. 9–16 min
    Look at the results

    Show the totals. Groups describe what was most and least popular and suggest why. Ask whether the result surprised them.

  4. 16–20 min
    Report one thing

    Each group prepares a sentence about the results. Hear a few, then ask partners to share an opinion they hadn’t expected.

Worth keeping in mind

The vote only takes a minute. Leave most of the time for the reasons behind it.

The English they’re using

Comparing amounts · Reporting a class result · Explaining a preference

Make it easier or harder

Keep it simple: Use “More students chose ___ than ___.”

Take it further: Estimate the proportion choosing each option and predict another class’s result.
