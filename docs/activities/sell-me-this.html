Activity 09 / 20 · Performance

Sell Me This

Practise persuasive language by making an ordinary object sound extraordinary.

Groups of 3–420 minutesOne object per group
Homeroom timer
20:00

Set up & model

Choose a length, then start.

Let’s give it a go.

Round 1

Words to get you started

“You need this because ___.” · “It is the most ___.” · “With this, you can ___.”

Teacher’s pocket guide

Choose. Model. Go.

Minimal-prep setup

Give each group a pencil, spoon, sock or other everyday object. Groups can draw an object if none is available.

Your 20-minute plan

  1. 0–3 min
    Show a quick model

    Hold up an object and give a playful one-sentence advertisement. Explain that imaginary features are welcome.

  2. 3–9 min
    Invent the product

    Groups choose a name, a customer and two selling points. Every member suggests at least one benefit.

  3. 9–16 min
    Write & rehearse

    Build a 30-second advertisement with a role or spoken line for everyone. Rehearse with expression and a memorable closing line.

  4. 16–20 min
    Perform & respond

    Groups perform to a neighbouring group. Each listener says which feature would persuade them to buy it; hear a few favourites.

English skills

Persuasion • Descriptive adjectives • Speaking with expression

Adjust the challenge

More support: Give a structure: product name → two features → “Try it today!”

More challenge: Anticipate a customer’s objection and answer it in the advertisement.
