Find Someone Who…

Class mingle

Timer ↓Prompt 1

  3. 3Ask one more thing

A few useful phrases

“Do you like ___?” · “Can you ___?” · “What kind of ___?”

Teacher guide Setup · 20-minute plan · English support

Students move around asking short questions and finding things out about their classmates.

You need: Notebooks

Before you start

Show the prompts. Students copy short labels and leave space for names. If there isn’t room to move, change partners at their desks.

The 20 minutes

  1. 0–3 min
    Show how to ask

    Turn “likes spicy food” into “Do you like spicy food?” Model a yes/no answer and one follow-up question.

  2. 3–9 min
    Find a few people

    Students ask different classmates and note a name for each yes. They need to hear the answer before writing it down.

  3. 9–16 min
    Find out a bit more

    Keep going with new partners. Ask students to add a follow-up, such as “What do you draw?” They should remember one detail about someone.

  4. 16–20 min
    Tell a partner

    Each student shares two things they found out. Take a few examples from the class if there is time.

Worth keeping in mind

Keep an ear out for students reading the prompt instead of asking a question. Model the question again and let them try.

The English they’re using

Forming questions · Listening for details · Talking about another person

Make it easier or harder

Keep it simple: Write the full questions beside the prompts.

Take it further: Use a different name for every prompt and ask two follow-up questions.
