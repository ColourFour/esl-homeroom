Category Sprint

Teams list words in a category for one minute, then explain a few of the words they chose.

Teams of 3–4Paper + pens
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“___ belongs because ___.” · “It means ___.” · “You can use it to ___.”

How to run it

Before you start

Each team needs paper. Show a category and use the one-minute timer. The word box on the page can collect a shared class list afterwards.

The 20 minutes

  1. 0–3 min
    Check the category

    Give two examples and explain that repeated words only count once. Students need to know what their words mean.

  2. 3–9 min
    Make a list

    Give teams a minute to write as many words as they can. Then each person explains one entry to the group.

  3. 9–16 min
    Try another category

    Repeat with a new category. Teams choose three useful words and put each into a sentence. Everyone contributes.

  4. 16–20 min
    Keep a few words

    Take a word and an explanation from each team. Partners choose one word to remember and use it in a sentence.

Worth keeping in mind

A long list is fine, but check that they can actually use the words. Spend time on two or three good examples.

The English they’re using

Recalling vocabulary · Explaining word meanings · Using words in sentences

Make it easier or harder

Keep it simple: Give two starter words and allow students to sketch before naming an object.

Take it further: Ask for an explanation in English before accepting a word.
