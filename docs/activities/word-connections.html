Word Connections

Link one word to the next and explain each connection. See where the group ends up.

Groups of 3–4No materials
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“___ makes me think of ___ because ___.” · “They both ___.”

How to run it

Before you start

Show a starting word. Groups go round in order. Use the shared list for a class example, or let groups build their chains aloud.

The 20 minutes

  1. 0–3 min
    Show a connection

    Try “Rain → umbrella, because it keeps you dry.” Make clear that they need a reason for the link.

  2. 3–9 min
    Build a chain

    Each person adds a word connected to the last one and explains why. Go round at least twice. Help each other when needed.

  3. 9–16 min
    Aim somewhere

    Start again and reveal the target word. Try to reach it in five links, explaining each step. Compare possible routes.

  4. 16–20 min
    Share an unusual link

    Groups share a connection that needed explaining. Partners retell part of their chain using because.

Worth keeping in mind

There can be several good connections. Ask them to make the link clear to someone outside the group.

The English they’re using

Making word associations · Giving reasons · Following another speaker’s idea

Make it easier or harder

Keep it simple: Offer two possible words if someone gets stuck.

Take it further: Reach the target in exactly five links without repeating a word.
