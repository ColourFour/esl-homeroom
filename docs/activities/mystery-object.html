Mystery Object

Give an ordinary object a new purpose. Groups decide what it does and explain how someone would use it.

Groups of 3–4One small object
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“It might be ___.” · “It could help you ___.” · “We think it is used for ___.”

How to run it

Before you start

Bring a small object, such as a binder clip or an empty box. If you don’t have one, use the name on the page. The extra challenge gives students a particular person to design for.

The 20 minutes

  1. 0–3 min
    Describe the object

    Show it and collect a few words about its shape, material and size. Ask what else it could be used for.

  2. 3–9 min
    Come up with ideas

    Each student suggests a use. The group asks how the ideas would work and chooses one to develop.

  3. 9–16 min
    Explain the invention

    Give it a name and prepare a short explanation. Everyone contributes a line about what it does or how to use it.

  4. 16–20 min
    Share with another group

    Groups explain their ideas to their neighbours. Ask the listeners which part they would like to try.

Worth keeping in mind

Once someone says the real name of the object, move straight to inventing another use for it.

The English they’re using

Describing objects · Using could and might · Explaining a use

Make it easier or harder

Keep it simple: Offer a few words: metal, plastic, round, hold, carry, open.

Take it further: Ask what could go wrong with the invention and how to fix it.
