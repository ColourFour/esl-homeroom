Rank It

Give each group a list to put in order. They have to agree, which gives them something to discuss.

Groups of 3–4Paper + pens
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“___ is more useful than ___ because ___.” · “I disagree because ___.”

How to run it

Before you start

Show the list. Groups make their own ranking on paper. Use the arrows on the board when you want to compare a group’s answer with the class.

The 20 minutes

  1. 0–3 min
    Set the situation

    Read the question and check any unfamiliar words. Each student chooses what they would put first.

  2. 3–9 min
    Hear everyone’s choice

    Go round the group. Each person names their top item and explains why. Encourage the others to ask questions.

  3. 9–16 min
    Agree on one list

    Groups write a shared ranking. Everyone should suggest a change or give a reason. Ask them to explain their first and last choices.

  4. 16–20 min
    Compare the lists

    Hear from a few groups. Where the rankings differ, ask students to explain why they made a different choice.

Worth keeping in mind

There is no answer sheet here. A sensible reason is enough, even if another group disagrees.

The English they’re using

Comparing things · Agreeing and disagreeing · Explaining choices

Make it easier or harder

Keep it simple: Use four items instead of six.

Take it further: Change the situation and ask whether their ranking still works.
