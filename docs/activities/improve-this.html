Improve This

Start with an obviously bad school idea. Groups make three changes and explain why their version is better.

Groups of 3–4Paper + pens
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“We should ___.” · “Students could ___.” · “It would be better if ___.”

How to run it

Before you start

Show one of the bad ideas. Groups need paper for their improvements. Use the extra condition only if they need more of a challenge.

The 20 minutes

  1. 0–3 min
    Find the problem

    Read the idea and ask what would go wrong. Give one suggestion using “We should…”

  2. 3–9 min
    Suggest changes

    Each student offers a fix. Ask who it would help and how it would make a difference.

  3. 9–16 min
    Agree on three fixes

    Groups choose their best three changes. Prepare a short explanation, with a line or a reason from each person.

  4. 16–20 min
    Compare versions

    Groups explain their plans to their neighbours. Listeners choose the most useful change and say why.

Worth keeping in mind

Push beyond “make it better”. What exactly would they change?

The English they’re using

Making suggestions · Using should and could · Explaining improvements

Make it easier or harder

Keep it simple: Give two possible changes and ask students to choose one.

Take it further: Keep the extra condition and explain how the plan still works.
