Would You Rather?

Choose between two options, then try to convince a partner. The reason matters more than the choice.

Pairs → groups of 4No materials
Time left
20:00

Explain & model

Start when the class is ready.

On the board

Prompt 1

A few useful phrases

“I’d rather ___ because ___.” · “Why would you choose ___?”

How to run it

Before you start

Put up a question. Students can raise a hand, point to a side or move across the room. Use the vote buttons if you want to record the class totals.

The 20 minutes

  1. 0–3 min
    Give an example

    Read the first question and give your own answer with a reason. Let students think for a moment before they choose.

  2. 3–9 min
    Compare answers

    In pairs, both students explain their choice. Ask them to follow up with “Why?” or “What about…?” Try a second question with a new partner.

  3. 9–16 min
    Try to change a mind

    Put up another question. In groups of four, students explain their choices and respond to each other. They can change sides if someone makes a good point.

  4. 16–20 min
    Take a few answers

    Hear two or three reasons from the room. Ask everyone to tell a partner which reason they found most convincing.

Worth keeping in mind

If everyone picks the same side, ask them to make the best case for the other one.

The English they’re using

Giving opinions · Using because · Asking follow-up questions

Make it easier or harder

Keep it simple: Use “I choose ___ because it is fun / useful / easier.”

Take it further: Ask them to find a drawback to their own choice.
