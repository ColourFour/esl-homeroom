One-Minute Expert

Give students a familiar topic and a little thinking time, then ask them to talk for up to a minute.

Prompt 1

A few useful phrases

“I think ___ because ___.” · “For example, ___.” · “Another thing is ___.”

How to run it

Before you start

Use a topic from the page. Students note a few words rather than a full script. Start with 30 seconds if a minute feels too long.

The 20 minutes

  1. 0–3 min
    Give a short example

    Talk for 20 seconds using an opinion, a reason and an example. Point out how those three parts gave you something to say.

  2. 3–9 min
    Prepare and try

    Students write three keywords. Each gives a 30-second talk to a partner, who asks one question. Swap.

  3. 9–16 min
    Have another go

    Keep the topic or choose a new one. Change partners and aim for a slightly longer talk. Use the one-minute timer for turns.

  4. 16–20 min
    Notice what helped

    Partners name a clear idea they heard. Ask students which keyword or question helped them keep going.

Worth keeping in mind

Allow pauses. The aim is to get a thought across without writing every sentence first.

The English they’re using

Speaking at length · Organising ideas · Giving examples

Make it easier or harder

Keep it simple: Aim for 20–30 seconds and give three useful words.

Take it further: Have the listener ask a question the speaker hasn’t prepared for.
